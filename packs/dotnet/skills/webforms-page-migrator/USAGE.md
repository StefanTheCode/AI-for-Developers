# webforms-page-migrator - usage

```text
Migrate Default.aspx to Razor Pages in LegacyShop.AspNetCore. Keep the URL and run the parity tests for it.
```

```text
Move Admin/Products.aspx to Blazor - the assessment picked Blazor for the inline grid editing.
```

```text
Port Site.Master and the MiniCart user control to a layout and a view component.
```

One page per run: behavior inventory first, logic out of the code-behind, then the new page on the same URL, then parity tests. The old page stays until decommission.
